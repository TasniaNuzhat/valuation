# Valuation & Term Sheet Bootcamp

Next.js 14 App Router, TypeScript, Tailwind CSS. The website is adapted from approved HTML preview Version 10.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` before deployment.

The hero photo is bundled at `src/assets/images/hero.jpg` and imported from the Hero component. All section components are in `components/all-components`; UI primitives in `components/ui`.

The application form is frontend-only and does not send or store submissions. Connect a real backend before using it to accept applications. Footer social symbols are not linked to unverified profiles.
